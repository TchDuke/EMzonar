# EMzonar — руководство

Программа считает проволочные антенны **методом моментов** (ядро семейства
NEC-2): вы задаёте антенну — файлом `.nec` или замыслом, — а программа отвечает
числами и картинками: входной импеданс и КСВ, токи по проводам, диаграмма
направленности, полоса по частоте, что наведёт на антенну приходящая волна.

Знать формат NEC при этом не обязательно: генератор строит антенну **по
замыслу** — «волновой канал на три элемента, 145 МГц, провод 4 мм», — а файл
пишет сам.

---

## 1. Запуск

```
./emzonar                          пустое окно
./emzonar антенна.nec              окно: структура, карточки, состояние
./emzonar антенна.nec --check      сводка: провода, сегменты, габариты, частота
```

Нужен Linux x86-64 и SDL2. Рядом с бинарём должен лежать каталог `assets` —
из него берётся шрифт.

## 2. Что программа считает

Всё это есть и в окне (меню **Счёт**), и ключом командной строки — ключи
удобны для скриптов и пакетных прогонов.

| Ключ | Что даёт |
|---|---|
| `--check` | сводка: провода, сегменты, габариты, частота |
| `--segments` | таблица сегментации в формате NEC |
| `--impedance` | входной импеданс, ток питания, КСВ, КПД, симметрия питания |
| `--pattern` | диаграмма направленности (нужна карточка `RP`) |
| `--sweep [--swr 2] [--ref 75]` | развёртка по частоте (нужна `FR` с числом точек) и **полоса числом** |
| `--converge` | сходимость: та же антенна на втрое густой сетке |
| `--receive` | что наведёт на антенне приходящая волна (`EX 1…3`) |
| `--near-field` | ближнее поле в точках, которые просит файл (`NE`, `NH`) |
| `--optimize gain\|fb\|swr\|band` | подбор размеров под одну цель — с показом ВСЕХ четырёх показателей до и после |
| `--shot файл.png [Ш В]` | снимок без окна; вместе с `--pattern` или `--sweep` снимает их |

**Земля** задаётся карточкой `GN`: идеальная, приближённая или **настоящая**
(проницаемость и проводимость). Над настоящей землёй импеданс считается точно —
интегралами Зоммерфельда, в том числе у антенны, **стоящей на грунте**. Есть
слоистая земля, обрыв (суша под антенной, вода в отдалении) и веер радиалов.

**Две схемы счёта.** У антенн с острыми изломами (рамки, квадраты) обычная
точечная привязка врёт в разы. Программа выбирает схему по задаче сама и
говорит об этом в ответе; `--nec5` заставляет считать смешанными потенциалами.

## 3. Антенна по замыслу

```
./emzonar --generate вых.nec --kind quad|yagi|whip [ключи]
```

Общее: `--freq МГц`, `--wire радиус_м` (либо `--strip ширина_м` — печатная
дорожка), `--segments N`. Без `--segments` сегментация берётся по замыслу.

- **рамки и каналы**: `--elements N`, `--spacing λ`, `--size λ`, `--gap λ`,
  `--ubend λ`, `--feeder λ`, `--height-m М`, `--azimuth °`, `--ground 0|1|2`;
- **решётка**: `--rows N`, `--cols N`, наклон луча фазой `--beam-tilt`,
  `--beam-lift`, гирлянда `--harness [Ом]`, прицеливание счётом `--aim`;
- **штырь**: `--height λ`, `--ground 0|1|2`, катушка укорочения `--coil`,
  `--coil-at`, `--coil-q`, радиалы `--radials N --radial-length λ`;
- **изоляция**: `--insul <проницаемость> --insul-radius <наружный, м>` —
  оболочка укорачивает антенну примерно на 4 % при εr = 3.

То же делает диалог **Антенна ▸ Генератор… (G)** в окне.

```
./emzonar --generate штырь.nec --kind whip --freq 145 --height 0.25
./emzonar --generate канал.nec --kind yagi --elements 3 --freq 145 --wire 0.004
```

## 4. Окно

- **Проект**: Открыть, Сохранить (F2), Перечитать, **Правка текстом (F6)** —
  файл как текст, F5 применяет; неудачная правка ничего не рушит и называет
  номер строки. Настройки — F4.
- **Вид**: спереди (1), сбоку (2), сверху (3), объёмный (4), вписать (F).
- **Антенна**: Генератор (G).
- **Счёт**: входной импеданс (I), сходимость сетки, поле в дальней зоне (E),
  приём (R). Сечения диаграммы переключаются: полярное/декартово (P),
  вертикальное/горизонтальное (V), электрическое/магнитное (M).

## 5. Файл `.nec`

Формат тот же, что у подлинной программы NEC, — чужие файлы читаются как есть.
Минимальная антенна: провод, земля, частота, источник.

```
CM Полуволновый диполь
CE
GW 1 21 0 -0.5 0 0 0.5 0 0.001
GE 0
FR 0 1 0 0 145
EX 0 1 11 0 1
XQ
EN
```

**Символьные переменные** — карточка `SY`: `SY half=0.25, wire=half/250`,
дальше `GW 1 11 0 -half 0 0 half 0 wire`. Имя задаётся до первого появления, и
выражение не переходит границу поля.

Готовые файлы — в каталоге `Examples/`; у каждого в первых строках `CM`
сказано, зачем он и на что смотреть.

## 6. Чего программа не делает

- **Сплошных поверхностей нет**: площадки NEC — отдельное уравнение. Экран за
  антенной задаётся сеткой, шаг крупнее λ/4 запрещён замером.
- **Сферическая сетка ближнего поля** не сделана и отвергается вслух;
  прямоугольная работает.
- **Ступенька берега** (вода ниже суши) не сделана; обрыв по горизонтали есть.
- **Веер радиалов правит отражённый луч, но не потери в ближнем поле под самой
  антенной** — они живут в матрице. Поэтому радиалы меняют диаграмму (в примере
  из `Examples/` это +2.3 дБ), а входной импеданс — нет. То же ограничение и у
  подлинной программы NEC.
- **Печатная антенна** считается круглым проводом эквивалентного радиуса;
  текстолит не учтён, и на деле она резонирует ниже расчёта.
- `--selftest` — приёмка **дерева разработки**: ей нужны эталонные файлы и
  таблицы, снятые с подлинной NEC, а в поставку они не входят. Из поставки она
  честно скажет, что не запускалась.
